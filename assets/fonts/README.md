# Fonts

Both families are served locally so the app keeps its typography with no network.

- **Plus Jakarta Sans** — variable 200–800, latin + latin-ext. The interface family.
- **JetBrains Mono** — variable 400–700, latin + latin-ext. Console output, log lines
  and ID readouts only.
